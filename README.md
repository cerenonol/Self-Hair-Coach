# SELF HAIR COACH: Her Açıdan Uzman Doğruluğu

## Proje Özet ve Amaç

**SELF HAIR COACH**, saç analiz süreçlerinde yaşanan insan hatasını (“Yamuk Açı, Kötü Işık”) ortadan kaldıran, **Yapay Zeka destekli mobil analiz uygulamasıdır**.  
Geliştirdiğimiz otonom sistem sayesinde kullanıcıların klinik inceleme için gereken **5 kritik açıyı** (Tepe ve Ense dahil) **hatasız** çekmesi garanti edilir.

**Slogan:** *“Her açıdan uzman doğruluğu”*  
**Hackathon Başarısı:** Klinik operasyonlarında veri hazırlama süresini **%70 azaltma potansiyeli**.

---

## ✨ Benzersiz Değer Teklifi (USP)

### 1. 🤖 Otonom AI Agent Sistemi (HUD)

Uygulamanın kalbi, çekim kalitesini anlık olarak denetleyen **4 Senkronize Akıllı Ajan**'dır.  
Bu ajanlar, kullanıcının ekstra çaba göstermesine gerek kalmadan en iyi sonucu sağlar.

| İkon | Agent Adı | Teknik Görev |
|------|-----------|--------------|
| 👁️ | **Vision** | Yüz ve Mesh Haritalama ile doğru çerçeveleme tespiti |
| 📐 | **Pose** | Gyroskop + İvmeölçer verileriyle milimetrik açı onayı |
| 💡 | **Lighting** | Exposure optimizasyonu ile gölgesiz, klinik uygun ışık |
| ✅ | **Quality** | Bulanıklık tespiti ve çok faktörlü kalite onayı |

---

### 2. 🛡️ Zorlu Açı Kılavuzlama Garantisi

Tepe (Vertex) ve Ense (Donör) gibi kullanıcının ekranı göremediği açılarda:

- Uygulama **Arka Kamera** moduna geçer.
- Vision + Pose ajanları, canlı görüntüyü **SVG Kılavuz Şablonu** ile eşleştirir.
- Uyum **%90** olduğunda uygulama otomatik olarak **3–2–1** geri sayım başlatır ve çekimi tamamlar.

**Sonuç: Hata Payı = %0**

## 🛠️ Teknik Mimari ve Stack

| Kategori | Teknoloji | Proje Bağlantısı |
|---------|-----------|------------------|
| **Frontend Core** | React / TypeScript / Vite | Ultra hızlı geliştirme, tip güvenliği |
| **Stil & Branding** | Tailwind CSS / CVA | Koyu Lacivert – Elektrik Mavisi lüks UI teması |
| **Native Erişim** | Gyro/Accel Sensörleri | Pose Agent için milimetrik açı doğrulama |
| **Animasyon** | Framer Motion | HUD ve AI state geçiş animasyonları |
| **Veri & Depolama** | Firebase (Firestore + Storage) | 5 yüksek çözünürlüklü fotoğrafın güvenli teslimi |
| **İkonografi** | Lucide React | Modern ve minimal ikon seti |
